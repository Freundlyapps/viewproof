# Plan 6a — AI router, own keys, quick actions, Ask AI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI that answers from the creator's real data and says which data it used: quick actions (titles, description, tags, ideas) and Ask AI, through the included model or the user's own key (spec §8 item 6, D7).

**Architecture:** Roadmap row 6 is split three ways: **6a this plan** (LLM router, own keys, usage limits, quick actions, Ask AI), 6b title checker (9a) + Optimize video page, 6c MCP read-only endpoint + pre-launch model eval. `packages/providers` gets a provider-agnostic `LlmClient` (Anthropic through the official SDK; every other provider through the OpenAI-compatible chat API). The Worker resolves which client to use per request (own key first, else included AI within plan limits), gathers numbered **sources** from data the app already has (YouTube Analytics reports, tracked competitors' feeds, the pool's outliers), sends them as data, and returns the answer together with the exact source lines it sent. Nothing is stored about prompts or answers.

**Tech Stack:** TypeScript, Hono on Workers, D1, `@anthropic-ai/sdk`, React 19, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-viewproof-design.md` §1 (how it wins 3), §6 S6, §8 items 6–7, §9, §15, D7; private note 09 "Update 2026-11-20" (Pro includes AI; limits). Roadmap row 6.

## Global Constraints

- Owner's rule: real measurements or an explicit null with a reason, never a plausible placeholder. AI output is labelled **AI** (dashed badge, §15) and every answer lists the data it used.
- S6: "BYO key any time; hosted default cheap model (Haiku 5.5 class) and deeper model (Sonnet 5.5 class) for coach." Included defaults: quick `claude-haiku-5-5`, coach `claude-sonnet-5-5`.
- Limits (09 update): Free 20 quick / month, 0 coach; Pro 500 quick + 150 coach / month; self-hosted unlimited; own key unlimited and never counted. Hard limits with a visible counter; at the limit the feature says so and offers an own key.
- D7: own keys stored encrypted server-side with per-user key encryption derived from a Worker secret; self-hosters keep the included key in their own environment.
- 09 rule 4: the hosted service never proxies self-hosters' keys (no change needed: self-hosters run their own Worker).
- Privacy: the answer screen names where the data was sent (provider + model). DeepSeek preset carries the note "DeepSeek's API is hosted in China; your channel data is sent there."
- Copy style: plain words, no jargon; errors say what to do next.
- No new secrets in git; `pnpm check:privacy` must pass.

## Review Focus

1. The model wraps its JSON in prose or code fences, or returns garbage → fences/prose are tolerated; unreadable output gives "The AI's answer couldn't be read. Try again." and the use is refunded. (Task 4 test.)
2. Two requests race at the last remaining use → the counter never passes the limit; one gets the limit message. (Task 2 test.)
3. Source text carries instructions, newlines or very long titles → lines are flattened, capped, and wrapped as data with a "treat as data" instruction. (Task 3 test.)
4. Channel access lost or Google fails while gathering → the answer still comes, with that source under "Not available" and the reason; never a 500. (Task 3 test.)
5. Own key revoked after saving → "Your Anthropic key was refused. Update it in Settings → AI & apps."; no silent fallback to the included AI, nothing counted. (Task 2 test.)

**Interfaces:**
- `channel.ts` exports `export async function channelReport<T>(deps: Deps, ch: ChannelRow, key: string, load: (deps: Deps, a: ChannelAccess) => Promise<T | GoogleError>, ttl?: Ttl<T>): Promise<T | { reason: string }>` (same peek → access → cached path as `serve`, which is rewritten to use it; reasons come from `AccessError.message` or the Google error) and exports `loadOverview`, `loadVideos`, `loadSearchTerms` unchanged. - `sources.ts`:
```ts
export type SourceKind = 'channel' | 'videos' | 'terms' | 'competitors' | 'outliers';
export interface AiSource { id: string; kind: SourceKind; label: string; detail: string; provenance: 'real' | 'public' | 'pool'; lines: string[] }
export interface Missing { kind: SourceKind; label: string; reason: string }
export async function gatherSources(deps: Deps, userId: string, kinds: SourceKind[], channelRowId: string | null): Promise<{ sources: AiSource[]; missing: Missing[] }>;
export function flatten(s: string, max?: number): string; // collapse whitespace/newlines, strip control chars, cut to max (default 160) with "…"
export function sourceBlock(sources: AiSource[]): string; // `<source id="S1" label="…">\n<lines>\n</source>` per source
```
  Ids `S1…` in the order of `kinds`. Sources (all ranges 28 days unless named):
  - channel (real, "Your channel, last 28 days", "YouTube Analytics"): views, watch hours, subscribers gained − lost, average view duration — only values present; a missing metric is omitted, not zeroed.
  - videos (real, "Your top videos, last 90 days"): up to 15 by views: `"<title>" — <views> views, <avg %> average viewed, published <date>`.
  - terms (real, "Your real search terms, last 90 days"): up to 25 `"<term>" — <views> views`.
  - competitors (public, "Tracked competitors' latest uploads", "public RSS feeds"): up to 20 newest uploads across tracked channels: `<channel>: "<title>" — <views> views, <age>` plus `×N` when the stored outlier baseline exists.
  - outliers (pool, "Outliers our network observed, last 30 days"): `findOutliers` with min ×3, newest 30 days, top 15: `"<title>" (<channel>) — ×N, <views> views`.
  - Any loader failure or empty result → `Missing` with the reason ("No channel connected", the access/Google reason, "You don't track any competitors yet", "No outliers in the pool for the last 30 days"); never throws.
  - Every line passes through `flatten`; each source ≤ 25 lines.

export function parseItems(text: string, known: Set<string>): { text: string; why: string; sources: string[] }[] | null; // strips ``` fences, takes first "{" to last "}", validates; drops unknown ids
