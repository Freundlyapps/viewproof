# Plan 6b — Title checker and Optimize video — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Optimize video page: a rule-based title checker with a comparison against niche outliers (spec §8 item 9a), and a per-video check of title, description and tags against the video's real search terms, ending in "Copy all" + "Open in YouTube Studio" (§15).

**Architecture:** Roadmap row 6 split: 6a (merged), **6b this plan**, 6c MCP + model eval. All checks are pure functions in `packages/core` (run in the browser, testable, same input → same output). The API adds one endpoint that returns one of the user's videos with its description, tags and its own top search terms (YouTube Analytics, last 90 days). The outlier comparison reuses `/api/outliers?q=`; AI suggestions reuse 6a's `/api/ai/quick` and are labelled AI.

**Tech Stack:** TypeScript, Hono on Workers, React 19, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-viewproof-design.md` §7 (checklist: each rule visible), §8 items 9a and 2, §15 (no write-to-YouTube in Phase 1: "Copy all" + "Open in YouTube Studio"), §6 S1/S2. Nav copy: "Check a video's title, description and tags against your real search terms, then copy them into YouTube Studio."

## Global Constraints

- 9a: "rule-based checks (length, keyword position, truncation in search/home preview) plus a comparison with titles of niche outliers; shows every reason, no opaque 0–100 score. Optional AI suggestions labelled as AI."
- Owner's rule: real value or explicit no-data with a reason. A comparison over fewer than 5 outlier titles shows "no data" with the count, not a percentage.
- Truncation is shown as an **approximate preview** (the title rendered at YouTube-like widths with line clamping), never as a computed pixel number.
- Rule thresholds are shown in each rule's text. Defaults reuse `DEFAULT_CHECKLIST` (title 20–70, description ≥ 250, tags ≥ 3) and `TITLE_LIMIT = 100`.
- No YouTube writes. Data API cost: `videos.list` with `part=snippet,contentDetails` = 1 unit per check, cached 6 h.

## Review Focus

1. A title with emoji, CJK or mixed case and a keyword with different casing/spacing → keyword match uses `normalizeKeyword` + word matching; position counts characters of the original title (code points, not UTF-16 units).
2. A video with no description, no tags, or tags missing from the API response → "No description" / "No tags", not a crash or "0 tags" from a guessed default when YouTube omitted the field (API omits `tags` when there are none — that does mean none).
3. A video id that isn't the user's (or doesn't exist) → 404 "Video not found on this channel", no data from another channel.
4. Search terms withheld by YouTube (empty list with a note) → coverage section shows YouTube's note; the title keyword falls back to what the user types.
5. Fewer than 5 outlier titles for the keyword → facts say "no data: only N outlier titles for this keyword", list still shows the N titles.

### Task 1: Checks in `packages/core`

**Files:** Create `packages/core/src/optimize.ts`; modify `packages/core/src/index.ts`; test `packages/core/test/optimize.test.ts`.

**Interfaces (produces):**
```ts
export interface OptimizeCheck { id: string; status: 'pass' | 'fail' | 'skip'; rule: string; detail: string }
export const KEYWORD_WITHIN = 40;      // keyword should start within the first 40 characters
export const SNIPPET_CHARS = 150;      // "first two lines" of a description
export const TAGS_LIMIT = 500;         // YouTube's limit for all tags together
export function checkTitle(title: string, keyword: string | null): OptimizeCheck[];        // ids: length, limit, keyword, keywordEarly
export function checkDescription(description: string, keyword: string | null, lengthSec: number): OptimizeCheck[]; // ids: length, keywordSnippet, chapters
export function checkTags(tags: string[]): OptimizeCheck[];                                  // ids: count, limit
export interface TermPlace { term: string; views: number; inTitle: boolean; inDescription: boolean; inTags: boolean }
export function termCoverage(terms: { term: string; views: number }[], v: { title: string; description: string; tags: string[] }): TermPlace[];
export interface TitleFacts { n: number; medianLength: number; withNumber: number; question: number; keywordEarly: number } // counts, not %
export function titleFacts(titles: string[], keyword: string): { ok: true; facts: TitleFacts } | { ok: false; reason: string };
```
Rules and copy (exact):
- title length: pass when `min ≤ chars ≤ max` of `DEFAULT_CHECKLIST.title`; rule "Title between 20 and 70 characters"; detail "`N` characters". Characters = code points (`[...s].length`).
- limit: rule "At most 100 characters (YouTube's limit)"; fail detail "`N` characters — YouTube won't accept it".
- keyword: skip with detail "No keyword given" when keyword empty; else pass/fail on `containsKeyword`; rule `Contains "<keyword>"`; fail detail "Not in the title".
- keywordEarly: skip when keyword missing or not contained; else find the first keyword word's position in the original title (case-insensitive, code points); rule "Keyword starts within the first 40 characters"; detail "Starts at character N".
- description length: rule "Description at least 250 characters"; empty → fail "No description".
- keywordSnippet: rule `"<keyword>" in the first 150 characters`; skip without keyword.
- chapters: uses `parseChapters(description, lengthSec)` from checklist; pass detail "`N` chapters"; fail detail = the parser's reason; rule "Chapters (timestamps starting at 0:00)". Skip for lengthSec ≤ 60 ("Short video").
- tags count: rule "At least 3 tags"; tags limit: rule "Tags within 500 characters together"; total counts each tag plus one separator between tags; a tag containing a space counts 2 extra (YouTube wraps it in quotes).
- termCoverage: per term, `containsKeyword` against title / description / each tag joined; keeps order.
- titleFacts: titles matching nothing are the caller's job; `< 5` titles → `{ ok:false, reason: "Only N outlier titles for this keyword; need 5 to compare" }`. `withNumber` = titles containing a digit; `question` = ending in "?" or starting with how/what/why/when/who/which/can/do/does/is/are (case-insensitive); `keywordEarly` = titles where the keyword's first word starts within 40 characters.

### Task 2: API — one video for optimizing

**Files:** modify `apps/api/src/youtube.ts` (client method), `apps/api/src/routes/channel.ts` (route), `apps/api/test/fake-youtube.ts`; test `apps/api/test/optimize.test.ts`.

**Interfaces:**
- `YouTubeClient.video(accessToken: string, videoId: string): Promise<VideoDetails | null | GoogleError>` — `videos.list?part=snippet,contentDetails&id=<id>`; null when no item. `VideoDetails { videoId; channelId; title; description; tags: string[]; publishedAt; durationSec: number | null }` (`tags` absent in the API → `[]`, which YouTube uses for "no tags").
- `GET /api/channels/:id/optimize/:videoId` → `OptimizeVideo { video: VideoDetails; terms: { term: string; views: number }[]; termsNote: string | null; period: { start: string; end: string }; fetchedAt: string }` (type in `packages/core/src/api-types.ts`). Video id must match `^[\w-]{11}$` else 400. A video whose `channelId` isn't this channel's `channel_id` → 404 `{ error: 'not_found', message: 'Video not found on this channel.' }` (also when null). Terms: `terms(deps, a, start, end, videoId)` over the 90-day period from `dailyFor(deps, a, '90d')`; none → `termsNote` = the existing NO_TERMS copy. Cache key `optimize:<videoId>:<today>` via `serve`.
